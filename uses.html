Uses

The hardware and software this site is built on. It's not new and it's not fast. That's part of the point. Constraints make you write better code.

Hardware

  • CPUIntel Pentium E5700 @ 3.0GHz (dual-core, 2008)
  • RAM4GB DDR2
  • OSWindows 10
  • EditorVS Code
  • BrowserSupermium

Why this setup

I'd rather build something fast and clean on old hardware than something heavy on a machine I don't have. Everything here is hand-written HTML, CSS, and a bit of JS. No frameworks, no build step, no giant dependencies. It loads in a blink because it has to.
